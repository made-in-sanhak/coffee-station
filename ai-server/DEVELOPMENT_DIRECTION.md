## 기능별 책임

- 자연어 해석: LLM이 요청의 조건을 추출하고 Python이 형식과 지원 범위를 검증한다.
  필요한 확인을 거친 조건을 검색에 적용한다. 필수 조건을 자동 완화하지 않는다.
- 메뉴·매장 추천: Python이 필수 조건 필터, 점수 계산, 정렬과 결과 구성을 담당한다.
  현재 요청을 과거 취향보다 우선하며 점수로 필수 조건 위반을 상쇄하지 않는다.
- 리뷰 요약·분석·추천용 특징 추출: Agent가 리뷰 도구를 사용해 근거를 수집·검증하고 결과를 저장한다.
  추천 요청마다 분석하지 않고 리뷰 변경 시 갱신하는 방향을 우선한다.
- 추천 시에는 저장된 분석 특징을 Python이 읽어 목적·취향 점수와 추천 근거에 반영한다.

## 리뷰 분석 원칙

단어 목록만 저장하지 않고 주제/특징, 긍정·부정 근거 리뷰 ID, 인용, 상황, 분석 시각과 버전을 보존한다.
상반된 의견과 평일/주말 등 맥락을 유지한다. 리뷰 의견을 검증된 매장 사실로 단정하지 않는다.
표시용 자연어 요약과 계산용 구조화 특징을 구분한다.
수정·삭제·숨김 리뷰의 근거와 분석 결과를 무효화·갱신한다.

Agent 흐름: 변경 확인 → 리뷰 조회 → 요약/특징 추출 → 근거 검증 → 필요 시 재조회/재분석 → 저장.
고정 처리 단계는 일반 코드로 구성하고, 추가 조회·수정 행동이 필요한 부분에 Agent Loop를 적용한다.
도구·모델 호출 수와 시간 제한을 두고 내부 사고 과정은 기록하지 않는다.
