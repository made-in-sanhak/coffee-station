# 로컬 MVP 실행과 검증 (2026-11-11)

우선 범위: 선택 조건 검색 → 자연어 조건 준비 → 사용자 확인 → 가격순 추천.
기존 로그인 화면의 **개발용 MVP 추천 테스트 (로그인 불필요)**에서 실행합니다.
지도·영수증·쿠폰·결제·Python 리뷰 Agent·운영 배포는 이 경로의 선행 조건이 아닙니다.

## 1. 백엔드

`backend`에서 아래 중 하나만 실행합니다. 기본 포트는 8080이며 기존 서버는 직접 종료하세요.

```powershell
npm run dev:mvp
# 또는: 기존 MySQL의 DEMO 가격 조회
npm run dev:mvp:db
```

두 명령 모두 자연어 추출은 mock으로 고정하여 외부 AI 호출을 하지 않습니다.
DB 모드는 루트 .env의 DB_*를 사용하며 데이터 생성·수정·초기화를 하지 않습니다.
MySQL을 먼저 실행하고 기존 seed 자료를 준비해야 합니다. DEMO 출처만 조회하므로
다른 출처 가격이나 검색 조건 밖의 가격은 결과에 포함되지 않습니다.

다른 터미널의 `backend`에서:

```powershell
npm run smoke:mvp
```

검색·준비·확인 3개 HTTP 요청을 수행하여 같은 결과·예산·가격 정렬을 검사합니다.
mock은 3000/4000원 2옵션이 정답이며 DB는 저장된 자료에 따라 다릅니다.
빈 결과를 DB 오류와 구분하며 외부 AI 실패를 mock으로 자동 대체하지 않습니다.

## 2. 앱

`frontend`에서 `npm start`, 다른 터미널에서 `npm run android:dev`를 실행합니다.
에뮬레이터의 기본 서버는 `http://10.0.2.2:8080`입니다.
USB 실기기는 `adb reverse tcp:8080 tcp:8080` 후 개발 앱 설정에서
`http://127.0.0.1:8080`을 저장합니다. Metro 기본 포트 8081도 USB 전달해야 합니다.

로그인 전 MVP 테스트 화면에서:

서버 포트를 바꿨다면 화면의 **MVP 서버 주소**를 수정하고 **서버 주소 적용**을 누르세요.
현재 실행해 둔 DB 서버는 에뮬레이터에서 `http://10.0.2.2:8084`로 접속합니다.

1. 아메리카노 / ICE / 4천 원 이하 → 선택 조건 검색.
2. `4천 원 이하 아이스 아메리카노 추천해줘.` → 자연어 조건 준비.
3. 조건을 검토한 뒤 확인 후 추천 → 1과 동일한 옵션.
4. `5천 원 미만 따뜻한 카페라떼 추천해줘.` → 준비·확인.
5. 지원하지 않는 문장에서는 추가 확인이 필요하며 자동 추천하지 않음.

가격 카드에는 매장·메뉴·온도·원문 사이즈·가격·이유·데이터 모드를 표시합니다.
DB 가격은 시연 자료이며 현재 판매 가격이나 검증된 확인일로 주장하지 않습니다.
자연어 mock은 위 두 문장만 지원합니다. 분당 제한(10회)에 걸리면 기다려야 합니다.
실제 Gemini는 별도 품질/비용 검증 과제로 남깁니다.

## 실제 검증

- 백엔드 빌드 및 기존 CJS 테스트 32개 통과.
- mock 서버 8083: 검색→준비→확인 일치, 3000/4000원.
- 로컬 DB 서버 8084: 읽기 전용 검색→준비→확인 일치, 10옵션 반환.
- 실제 Gemini 호출·DB 쓰기·운영 배포 없음. 기기 화면의 시각 검증과 별도입니다.

별도 포트를 검증할 때는 `$env:MVP_TEST_URL='http://127.0.0.1:8084'`를 설정하고
`npm run smoke:mvp`를 실행합니다. 서버 실행 포트는 `$env:PORT='8084'`로 지정합니다.
